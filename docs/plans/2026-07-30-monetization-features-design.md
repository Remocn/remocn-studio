# remocn Pro — дизайн платного пакета

> Результат брейншторма 2026-07-30. Рамка, согласованная с владельцем: форму оплаты
> выводим из фич; серверную часть строить готовы; платящая аудитория — соло-фаундеры
> (приоритет), команды/devrel, контент-мейкеры. Дополняет раздел 5 в `docs/PLAN.md`.

## Резюме

Одна подписка **remocn Pro** (~$10/мес или ~$96/год), четыре фичи в порядке постройки:

1. **Share-ссылка** — рендер публикуется на remocn.dev страницей с плеером.
2. **Ревью-комментарии** — зритель кликает в кадр и пишет замечание; оно приходит в чат
   сессии как референс, и агент правит по чужому фидбеку.
3. **Polish pass** — агент сам снимает кадры готового видео, находит визуальные проблемы
   и исправляет их. Инференс — на подписке пользователя, себестоимость для нас нулевая.
4. **Экспорт-пресеты** — один ролик выходит в 16:9 / 9:16 / 1:1 под платформы, пакетно.

Бесплатной остаётся вся сегодняшняя петля: чат → превью → inspect/snapshot → экспорт mp4.
Free-уровень шеринга (3 активные ссылки с бейджем «Made with remocn studio») — это
одновременно и пробник, и вирусный канал.

Почему такой состав: share/ревью создают **серверную** ценность — единственное, за что
честно брать подписку, и их нельзя получить, «собрав из исходников»; Polish pass — козырь,
который не скопировать связкой «Claude Code + скилл», потому что он требует владения
превью, снапшотом и агентом в одном цикле — а этим владеет только studio.

## Фича 1: Share-ссылка

**Жест.** После успешного экспорта (или рендера любой версии) — кнопка «Поделиться».
Приложение загружает mp4 + постер (кадр через существующий still-пайплайн) + метаданные
(название, длительность, fps, размер композиции) на api.remocn.dev под токеном аккаунта.

**Страница** `remocn.dev/v/<id>`: обычный `<video>` с постером, заголовок, кнопка embed.
Сознательно **не** Remotion Player и не серверная компиляция — сервер хранит и отдаёт
готовый файл, ничего из Remotion на сервере не исполняется (лицензионно чисто, дёшево,
нечему ломаться).

**Версии.** Повторный share из той же сессии создаёт v2 на той же странице с
переключателем версий — история согласования живёт в одном месте.

**Уровни.** Free: 3 активные ссылки, 720p, бейдж. Pro: без лимита, до 4K, без бейджа,
версии, свой слаг, пароль на ссылку (позже).

**Метаданные — контракт для ревью.** fps и размер композиции сохраняются с версией:
они превращают таймкод и прямоугольник комментария обратно в кадр и регион.

## Фича 2: Ревью-комментарии

**Жест зрителя.** На странице шеринга: пауза → клик или рамка на кадре → текст → имя
(аккаунт не нужен, комментатор — гость). Комментарий хранится с таймкодом и
нормализованным прямоугольником — та же геометрия, что у снапшот-кропа.

**Жест автора.** Приложение забирает комментарии по своим ссылкам (поллинг при открытой
сессии + проверка при открытии). В чате — карточка «3 новых комментария к v2»; клик по
комментарию кладёт его в композер референсом (механика `shared/references.ts`, новый вид
рядом с `[Element #N]`), а приложение через warm-render добавляет кадр на этом таймкоде
как вложение. Агент получает: текст замечания, кадр, регион, таймкод → и правит.

**Границы v1.** Без тредов, без резолва на странице — только «замечание → в чат».
Резолв — это следующая версия видео.

## Фича 3: Polish pass

**Жест.** Кнопка «Полировка» в чате. Приложение:

1. Берёт границы сцен (метаданные композиции; фолбэк — N равномерных кадров) и снимает
   стиллы через warm-сессию рендера (после прогрева ~100 мс/кадр — уже измерено в #21).
2. Собирает ход агенту: кадры + рубрика (вылезание текста за край и safe-area, контраст,
   типографическая шкала, выравнивание, согласованность с брендом, рваный тайминг).
3. Агент вносит правки обычным путём (permission-гейт работает как всегда), приложение
   пере-снимает изменённые сцены и делает второй проход. Жёсткий потолок — 2 итерации.
4. В транскрипте — отчёт: «проверено 8 кадров, исправлено 3 замечания, 1 оставлено вам».

**Экономика.** Все токены — подписка пользователя (Claude Pro/Max), наших затрат нет.
Это локальная фича, гейтится состоянием подписки из аккаунта (оффлайн-грейс 30 дней).

**Риск и его смягчение.** Главный риск — агент «улучшит» то, что было задумано. Поэтому
рубрика консервативна (только объективные дефекты), правки идут через обычный диффовый
транскрипт, и весь проход — одна сессия, которую можно откатить `git checkout` (проект
и так в git у пользователя).

## Фича 4: Экспорт-пресеты

**v1 (честный минимум).** Пресет = список целевых форматов. Рендер той же композиции с
переопределением размеров + автоматический прогон safe-area-проверки из Polish-механики.
Очередь: форматы рендерятся последовательно с одним прогревом.

**v1.5 (агентная адаптация).** «Адаптируй под 9:16» — отдельный ход агента, который
меняет layout/масштаб под вертикаль, с превью до рендера. Это отличает нас от тупого
кропа, но не блокирует v1.

Зависимость: экспорт (#227) должен существовать. Пресеты — первое, что делает его
«регулярным», а не разовым.

## Аккаунты, биллинг, enforcement

- **Вход** — GitHub OAuth на remocn.dev, приложение получает токен (deep link или
  device-code, решается при имплементации). Аккаунт нужен только для Pro-фич; без него
  приложение работает как сегодня.
- **Биллинг** — Paddle или Lemon Squeezy (merchant of record: налоги ЕС/США не наши).
  Подписка ~$10/мес / ~$96/год, 14 дней триала Pro. Командный тариф (~$25/мес,
  общие пространства ссылок) — после появления спроса, не в v1.
- **Enforcement.** Серверные фичи гейтятся сервером естественно. Локальные (Polish,
  пресеты) проверяют подписку через аккаунт с оффлайн-грейсом; обход сборкой из
  исходников принят осознанно — платящий сегмент покупает время, не невозможность обхода.

## Порядок постройки

```
#227 экспорт ──► пресеты v1
     │
аккаунты + share v1 (бета, бесплатно) ──► биллинг ──► ревью-комментарии
     │
Polish pass (независим от сервера, можно параллельно)
```

1. **#227 / #228** — пререквизит всего (этап A из PLAN.md, без изменений).
2. **Аккаунты + Share v1** — выкатить бесплатной бетой до включения денег: набрать
   живые ссылки-витрины и обкатать хранилище.
3. **Биллинг** — включить Pro-лимиты шеринга. Первый доллар здесь.
4. **Polish pass** — параллельная дорожка, не ждёт сервера.
5. **Ревью-комментарии** — самая дорогая и самая «командная» фича, последней.

## Риски

- **Хостинг видео** = хранилище и трафик. Ограничен лимитами ссылок и 720p во Free;
  считать по факту беты, лимиты — ручка, а не архитектура.
- **Модерация**: публичные страницы с чужим контентом → ToS, кнопка report, unlisted
  по умолчанию.
- **Anthropic ToS** для продаваемого приложения на подписочной авторизации — перечитать
  до включения биллинга; запасной вход по API-ключу остаётся в плане (PLAN.md 5.5).
- **Лицензия Remotion**: сервер не исполняет Remotion вообще (только отдаёт mp4) — это
  осознанное проектное ограничение, удерживающее вопрос на стороне пользователя;
  письменный запрос в Remotion всё равно нужен до продаж (PLAN.md 5.5).
